# Government Scheme Navigator

## Project Description

Government Scheme Navigator is a web application that helps users find suitable government schemes based on their personal eligibility details.

Users can select their category and provide details such as age, income, occupation, and state. The application checks the eligibility criteria and displays suitable government schemes.

## Features

- User-friendly interface
- Scheme eligibility checking
- Category-based scheme recommendations
- Eligibility match score
- Eligibility checklist
- Scheme details and information

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
